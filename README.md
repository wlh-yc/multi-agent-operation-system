# 多Agent协同运营自动化系统 Multi-Agent 智能体协同调度、任务自动化执行系统 

## 项目介绍  

## 	多智能体分工协作：任务调度、数据处理、任务执行、状态监控、报告生成 - 轻量化架构，纯Python无第三方复杂依赖 - 可扩展对接AI大模型、定时任务、业务自动化 

## 运行方式 

```bash python main.py
bash python main.py
```

## 项目结构



```
├── main.py               # 程序入口
├── agent_manager.py      # 智能体管理中心
├── agents/               # 各业务智能体
├── tasks/                # 任务池管理
└── utils/                # 工具日志
```
